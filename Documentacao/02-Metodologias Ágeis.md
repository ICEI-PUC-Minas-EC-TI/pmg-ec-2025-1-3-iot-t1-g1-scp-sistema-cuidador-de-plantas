## Gerenciamento de Projeto


# Metodologia

O projeto foi desenvolvido de forma individual, com planejamento pessoal e organização das tarefas para garantir o avanço eficiente das etapas. O trabalho foi dividido em fases, contemplando desde a pesquisa inicial até a implementação e testes do sistema.

Embora não tenha sido utilizada uma metodologia formal de gestão, o processo seguiu uma sequência lógica:

Levantamento dos requisitos e definição dos componentes necessários;

Desenvolvimento do circuito e montagem da estufa;

Programação do ESP32 para leitura dos sensores e controle dos atuadores;

Desenvolvimento do aplicativo Android para monitoramento e controle remoto;

Testes integrados do sistema e ajustes finais;

Documentação do projeto.

Essa organização permitiu um acompanhamento claro do progresso e a identificação de melhorias durante o desenvolvimento.

### Divisão de Papéis


Como o projeto foi desenvolvido de forma individual, todas as responsabilidades foram assumidas por um único participante, que atuou nas seguintes funções:

Scrum Master / Desenvolvedor / Documentador: Leonardo de Souza Fernandes


### Processo

O trabalho foi conduzido em etapas planejadas e sequenciais. Cada fase foi concluída antes do início da próxima, garantindo que os requisitos fossem atendidos de forma gradual e controlada.

Não houve o uso de processos formais como Scrum ou Kanban, porém, o planejamento pessoal incluiu o registro das tarefas a serem feitas e o monitoramento do progresso para manter o foco e a organização.
 

### Ferramentas

As ferramentas utilizadas no projeto foram:
Arduino IDE: para a programação do microcontrolador ESP32.
MySQL Workbench: para modelagem e gerenciamento do banco de dados SQL.
MQTTBox: para testes da comunicação via protocolo MQTT.
Java(IntelliJ):para o desenvolvimento do aplicativo Android em Java.
